# Variation-of-Cicphers-java

Command-line program implementing three classic ciphers, each with encrypt and decrypt:

- Keyword substitution cipher
- Columnar transposition cipher
- Vigenere cipher

Letter case is preserved. Digits, spaces and . ? ! , pass through unchanged
(the columnar cipher may move them).

## Run
javac MamadalievProgram1.java
java MamadalievProgram1

Choose a cipher, choose encrypt or decrypt, enter a keyword and your text.
Enter 0 at the first menu to quit.
